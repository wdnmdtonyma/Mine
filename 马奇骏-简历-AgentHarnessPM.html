Flux 字节内部多 Agent 研发协作平台 2026.03 — 至今

定位面向组织协作的多 Agent 研发平台，统一上下文编排 Agent 与成员协同，推动需求从构思到上线

  • 项目发起人，从 0 到 1 定义产品定位与架构，主导「多 Agent 编排、统一上下文、研发链路闭环」核心设计

  • 建设研发后链路 Harness 能力（Spec Driven、极速部署、LogID 分析），让 Agent 延展到测试、调试与上线

精准命中用户需求，周活迅速破万

Aime 字节内部通用 Agent 产品 2025.07 — 2026.03

定位通过 Skills、MCP 串联研发平台与工具链，动态组装 Worker 处理研发全场景复杂任务

  • 优化 Agent 效率层能力：任务拆解、上下文构建、Skill 生产，提升复杂工程任务的执行能力
  • 建设研发链路 Harness 能力，打通云环境、测试、验证、调试分析，使 Agent 从"生成代码"升级为"可交付"
  • 推动 SDD、本地/云端 Handoff、高并发 Worker 等能力建设，覆盖方案拆解、测试验证与人机协作

周活跃用户 7.5 万，渗透 90% 研发群体，成为内部使用频率最高的 AI 工具之一
